# Roadmap

## Near term

- Add repeated nested cross-validation without using the test set for architecture selection.
- Add shot-based sampling and configurable depolarizing/readout noise studies.
- Compare central-difference saliency with permutation, integrated-gradient, and gate-ablation views.
- Add uncertainty intervals across seeds and bootstrap intervals on frozen-test metrics.

## Research extensions

- Execute transpiled circuits on accessible hardware and report the complete resource budget.
- Test explanation stability under circuit reparameterization and measurement noise.
- Add multiclass data re-uploading and measurement-head ablations.
- Evaluate larger open datasets while keeping classical controls compute-matched.

No roadmap item presupposes quantum advantage.
